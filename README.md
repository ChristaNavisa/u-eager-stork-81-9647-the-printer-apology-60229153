Entry for [The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153) on make.fun.

The program writes one apology to `/output/entry.txt`: an office printer apologizing for eating page 47 — the only page that ever thanked it. The gate requires 1–120 characters of UTF-8 text on one line; this entry is 74 characters on one line, no trailing newline.

> I apologize for eating page 47. It was the only page that ever thanked me.

The joke is the reversal at the end: of all the pages the printer ever swallowed, it destroyed the one page that was kind to it.

Run with Node 22+:

```sh
node main.ts
```
